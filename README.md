# My site

Plain HTML/CSS. No build step.

## Edit
- Replace "Your Name", "your-name" and the links in every .html file (search and replace). Replace images/profile.svg with your photo (update the src in index.html).
- Paste your LinkedIn text into posts/pongos.html.
- Put photos in /images (compress first: squoosh.app), then use <img src="../images/file.jpg">.
- Videos: prefer YouTube embeds. Small clips can go in /videos.

## New post
1. Copy posts/pongos.html to posts/new-name.html and edit.
2. Copy the <a class="post"> block in blog.html (and index.html) and point it to the new file.

## Host free
- Netlify: drag this whole folder onto app.netlify.com/drop
- GitHub Pages: push to a repo, then Settings > Pages > deploy from main branch, root folder.
- Cloudflare Pages: upload the folder as a direct upload.
